# Demo Flow Screenshots

This folder contains screenshots used to support SARE demo walkthroughs.

Screenshots are optional but recommended for capstone reviews and stakeholder presentations.

---

## Demo Flow 1 — Risky Sign-in

Recommended screenshots (in order):

1. **01-incident-overview.png**
   - Sentinel incident summary
   - Rule name, severity, timestamp

2. **02-entities.png**
   - User entity
   - IP address
   - Location details

3. **03-enrichment-results.png**
   - SignInLogs enrichment query output
   - Risk level and authentication method

4. **04-sare-decision-summary.png**
   - SARE-generated incident comment
   - Risk score and explanation

5. **05-approval-request.png**
   - Approval required indicator
   - Recommended action (e.g., account suspension)
