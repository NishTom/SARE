# SARE — Security Autonomy Reasoning Engine

SARE is a documentation-first architecture for building AI-assisted security detection triage and response on top of Microsoft Sentinel.

## Goals
- Reduce analyst time-to-triage using consistent decision pipelines
- Keep response actions governed, auditable, and safe by design
- Provide repeatable demos (capstone-ready) that show end-to-end value

## Repository Map
- architecture/  System design, case model, agent architecture, decision pipeline
- demo/          Scenario walkthroughs and screenshots
- sentinel/       Analytic rules, playbooks, and KQL assets
- governance/     Approval model, guardrails, audit logging
- market/         Positioning, pricing, and go-to-market
- roadmap/        Versioned plan (capstone → MVP → future)
- diagrams/       draw.io diagrams

## Status
Documentation-first. Assets will evolve into an MVP implementation.
